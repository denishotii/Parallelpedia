# Parallelpedia Frontend

React + Vite + TypeScript frontend for Parallelpedia.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Create `.env` file (optional):
```bash
cp .env.example .env
# Edit .env if your backend is running on a different URL
# Default: http://localhost:8000
```

3. Run development server:
```bash
npm run dev
```

The app will be available at `http://localhost:5173`

## Build

```bash
npm run build
```

## Features

- Side-by-side article comparison
- Color-coded segment analysis
- Trust score visualization
- Community Note publishing to DKG
- Responsive design with TailwindCSS
